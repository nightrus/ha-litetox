# Litetox Server для Home Assistant

Интеграция для модулей **ALTOX** (WBUS-5 GPS, GSM-5 и др.), подключённых к собственному серверу **litetox**: это минимальный Wialon IPS сервер с MariaDB. Модуль отправляет данные на сервер по GPRS, а Home Assistant забирает их с сервера по HTTP API.

```
ALTOX ──Wialon IPS/TCP──▶ litetox (+MariaDB) ◀──HTTPS (опрос)── Home Assistant
```

## Возможности
- Настройка через UI: адрес сервера, API-токен, IMEI трекера и название.
- При добавлении IMEI регистрируется на сервере, и сервер принимает подключения **только** от зарегистрированных IMEI. При удалении интеграции IMEI отключается.
- Одно устройство со всеми сущностями:
  - **отопитель**: выключатель START/STOP, статус работы, пламя, температура отопителя, оставшееся время;
  - **автомобиль**: напряжение, температура салона, скорость, пробег, движение, местоположение (`device_tracker`);
  - **SIM**: баланс, уровень сигнала GSM, сота, прошивка;
  - **кнопки**: «Запросить статус», «Запросить баланс», «Запросить соты GSM»;
  - **выход OUT** (ACTIVATE/DEACTIVATE). По умолчанию эта сущность выключена.
- После отправки команды интеграция часто опрашивает сервер, пока модуль не ответит, поэтому состояние обновляется через несколько секунд, а не на следующем плановом опросе.
- Сервисы:
  - `litetox.start_heater` с параметром `minutes` (10–120);
  - `litetox.send_command`, который отправляет модулю любую команду из инструкции ALTOX (`STATUS`, `START:30`, `STOP`, `ussd`, `gsminfo`, `READ`…).

## Установка
HACS → Custom repositories → `https://github.com/nightrus/ha-litetox` (Integration) → установить → перезапустить HA → «Добавить интеграцию» → **Litetox Server**.

## Параметры
- **Интервал опроса**: по умолчанию 15 с.
- **Время работы отопителя** для выключателя: 0 означает настройку модуля (`TIME1`).

## Сервер
Исходники сервера лежат отдельно (`litetox/server`: Python, aiohttp, PyMySQL, MariaDB, docker compose). API:

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | версия, без авторизации |
| GET/POST | `/devices` | список / регистрация IMEI |
| DELETE | `/devices/{imei}` | отключить IMEI |
| GET | `/state/{imei}` | текущее состояние |
| POST | `/cmd/{imei}` | `{"command": "STATUS"}` → id команды |
| GET | `/cmd/{imei}/{id}` | статус команды и ответ модуля |
| GET | `/history/{imei}?type=positions\|heater\|balance\|commands` | история |

Все запросы, кроме `/health`, требуют заголовок `Authorization: Bearer <API_TOKEN>`.

На модуле адрес сервера задаётся SMS-командой, например `IPADDR2:<ip>,IPPORT2:<port>,TRACKING1`. Слот 1 можно оставить для ALTOX.
